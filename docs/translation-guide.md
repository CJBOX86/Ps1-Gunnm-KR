# 『총몽 화성의 기억』 PS1 한국어 번역 지침

재번역·추가 번역 때 따르는 문체·표기 규칙. 장 단위 묶음은 `python tools/TRANSLATE/tr_batch.py`로 `work/tr/`에 만든다.

## 입력·출력
- 입력: `work/tr/<묶음>.in.json` — 블록(장면)별로 `context_all_src`(그 장면의 원문 전체, 흐름 파악용)와 번역할 `lines`(id, src)
- 출력: `work/tr/<묶음>.out.json` — `{"줄 id": "번역문", ...}` 형식의 JSON 하나. 입력의 모든 줄 id를 빠짐없이 넣는다
- 다 쓰면 반드시 검사: `python tools/TRANSLATE/tr_batch.py check work/tr/<묶음>.out.json` (저장소 최상위에서 실행). "문제 0건"이 될 때까지 고친다
- 다른 파일(특히 assets/ 아래)은 절대 수정하지 않는다

## 표기 규칙 (어기면 검사 실패)
- 중괄호 코드 `{WS2503}` `{b3}` `{br}` `{WP-200+050}` `{[1}` `{i010}` 등은 원문과 **같은 종류·같은 순서로** 그대로 둔다
  - `{b2}`/`{b3}` 등은 글자색, `{br}`은 색 해제(줄바꿈 아님). 보통 `{b3}이름：{br}대사` 형태 — 이름도 번역한다 (용어집)
  - `{[0}` `{[1}` 등은 선택지 표시. 위치 유지
  - `{w+02}` 같은 `{w±NN}`은 줄바꿈으로 계산된다 (층 선택창: 질문 뒤 선택지가 새 줄)
- 실제 줄바꿈(JSON의 `\n`)은 게임 줄바꿈, `{page}`는 페이지 넘김. 이 둘은 위치·개수를 자유롭게 바꿔도 된다
- **한 줄은 25칸 이하** (이름과 `：` 포함, 한글·전각문자·공백 모두 1칸). `{WS2001}`처럼 창 코드가 있으면 앞 두 자리(20)가 그 대사의 줄 너비. 넘으면 단어 경계에서 직접 `\n`으로 줄을 바꾼다
- 창 높이(`{WS2503}`의 뒤 두 자리 = 3줄)를 넘기면 `{page}`로 나눈다. 창 코드가 없는 대사는 3줄 이내 (검사함)
- 문장부호: 마침표 `.`, 물음표 `？`, 느낌표 `！`, 말줄임 `・・・`, 쉼표는 `,`(자동으로 `、`로 바뀜), 괄호 `＜＞` `「」` `（）`는 원문처럼. 따옴표 `"` `'` 사용 금지 (폰트에 없음) → 「」 사용
- 띄어쓰기는 일반 공백(반각 ' '). 원문의 전각 공백 `　`이 줄 맞춤용(아이템 설명 들여쓰기 등)이면 그대로 둔다
- 한글 외에 쓸 수 있는 것: 원문에 나오는 전각 숫자·영문·기호(０-９ Ａ-Ｚ ａ-ｚ ・：？！ー／～（）「」＜＞＋－×), 반각 숫자/영문은 자동으로 전각 변환됨. 한자·가나는 쓰지 않는다
- **`DATA/`로 시작하거나 `M5/L/MP999_0@`로 시작하는 id는 원문보다 글자 수가 많으면 안 된다** (파일 크기 고정). 간결하게

## 용어·문체
- 용어집 `assets/translation/glossary.json`을 먼저 읽고 반드시 따른다 (갈리, 이드, 유고, 자렘, 고철마을, 헌터 워리어, 모터볼 …). `style` 항목의 말투 규칙(데크맨 ~다쥬, 넷맨 ~할지어다, 호칭)도 따른다
- 이미 번역된 장면과 일관되게: 필요하면 `assets/translation/segments/*.json`에서 같은 인물의 기존 `ko`를 참고해도 된다 (수정은 금지)
- 용어집에 없는 고유명사는 일본어 발음에 가깝게 음역하고, 같은 묶음 안에서 일관되게 쓴다
- 원작 『총몽』 국내판 분위기의 자연스러운 한국어. 직역투(～인 것이다, ～하는 것이었다) 피하기
- 말투: 갈리 = 반말(친한 사이)·씩씩함, 이드 = 다정한 반말, 곤즈 = 투박한 노인 말투, 시민·상인 = 상황에 맞게. 같은 인물은 묶음 내 일관
- 게임 시스템 문구(세이브, 아이템, 엔트리 등)는 짧고 명확하게: セーブ=세이브, アイテム=아이템, データ=데이터
- 의성어·웃음(ハハハ, フフフ, キャハハハ)은 하하하, 후후후, 꺄하하하처럼 자연스럽게
- 원문에 없는 정보를 덧붙이지 않는다
