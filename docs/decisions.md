# 결정 기록

한글화 범위·표기·글꼴처럼 사람이 정한 방향을 기록한다. 결정마다 상태, 질문, 선택지, 선택과 이유, 재검토 조건을 남긴다.

## D-001 한글화 범위

- 상태: 제안 (사람 결정 대기)
- 질문: 첫 릴리스가 포함할 범위는?
- 근거 기준선: [초기 조사 1차](../research/survey/2026-10-06-initial-survey.md). 메뉴 문자열은 위치 확인, 본편 대사는 미발견
- 선택지:
  1. 메뉴·시스템 + 본편 대사 (그래픽 텍스트는 추후) — 추천. 플레이 경험의 핵심. 대사 위치 확인이 선행 조건
  2. 전체 (영상 자막·그래픽 텍스트 포함) — 비용 최대, 그래픽 복원 작업 필요
  3. 메뉴·시스템만 — 빠르지만 게임 이해에 기여가 작음
- 재검토 조건: 대사 모집단·저장 방식 확인 후

## D-002 실행 관측 도구

- 상태: 채택 — 선택지 1 (사용자가 emucap 설치·사용을 진행, 2026-10-06). 원본·패치 이미지 모두 정상 구동 확인
- 질문: RAM·VRAM 관측과 입력 자동화에 어떤 도구를 쓸까?
- 근거 기준선: 사용자가 DuckStation(+BIOS)에서 원본 실행을 확인함. emucap 1.0은 PS1을 Mednafen 어댑터로만 지원
- 선택지:
  1. emucap + Mednafen 설치 — 추천. 에이전트가 화면·메모리·중단점을 직접 다뤄 반복 실험 비용이 낮다. 설치 작업과 BIOS 배치 필요
  2. DuckStation만 사용 — 사람이 디버거·메모리 덤프·세이브스테이트를 수동 제공 (HITL 요청 단위로 진행). 설치 비용 없음, 반복 비용 높음
- 재검토 조건: 어댑터가 이 게임을 정상 구동하지 못할 때

## D-003 번역 진행 방식과 표기 기준

- 상태: 채택 (2026-10-06, 사용자 선택)
- 질문: 본편 대사(직접 번역할 줄 13,399개)를 어떻게 번역하고, 고유명사는 어떤 표기를 따를까?
- 선택지: (1) Claude 초벌 번역 + 사람 검토 — 추천, (2) 사람이 직접 번역, (3) 일부만 시험 번역 후 재결정 / 표기: 정발판 『총몽』, 일본어 발음, 용어집 검토 후 결정
- 사람의 선택: **Claude가 초벌 번역**(상태 draft, 사람은 검토·수정), 표기는 **국내 정발판 『총몽』**
- 진행: 장(폰트) 순서대로 묶음 번역 → `tools/TRANSLATE/tr_batch.py` 검사·반영 → 개발 빌드·화면 확인. 용어집 `assets/translation/glossary.json` — 정발 표기를 확인하지 못한 항목은 `guess`로 표시해 사람 확인 대상으로 둔다
- 재검토 조건: 사람 검토에서 문체·용어 방향이 바뀔 때

## D-004 배포용 한글 글꼴

- 상태: 채택 (2026-10-07, 사용자 선택)
- 질문: 패치에 넣을 한글 글리프를 어떤 글꼴로 그릴까? (개발 빌드는 Windows 굴림 12px — 패치에 글리프 이미지가 들어가므로 배포 불가)
- 근거 기준선: 글리프는 13x13 칸, 흑백 1비트(4플레인에 한 글자씩)라 안티앨리어싱 불가. 후보를 같은 조건으로 그린 비교 `work/font_compare.py` → `work/font_compare.png`
- 선택지: Galmuri11 12px(추천 — 작은 크기용 도트, 굴림과 비슷한 선명도), Galmuri9 10px(작아 듬성함), NeoDunggeunmo(16px 도트라 12px 축소 시 뭉개짐, 원래 크기는 칸 초과), 나눔고딕(가늘고 덜 또렷), Pretendard(가늘고 복잡한 글자 뭉개짐). 모두 SIL OFL 1.1
- 사람의 선택: **Galmuri11** (v2.40.4) — `assets/fonts/sources/galmuri11/` (파일·해시·라이선스), `config/build.json` `glyph_render.font`
- 화면 확인: 타이틀, LOAD 메뉴, 프롤로그 대사 (`work/galmuri_ingame.png`)
- 배포 시: OFL 고지(`assets/fonts/sources/galmuri11/OFL.txt`)를 패치와 함께 배포. 글꼴 이름 'Galmuri'는 예약 이름이라 글꼴을 수정해 별도 글꼴로 배포할 때는 쓰지 않는다(패치 안 글리프 사용은 해당 없음)
- 재검토 조건: 사람 검수에서 가독성 문제가 나올 때
